# Timeline

**Key:** 🟦 = real-world trend (backdrop only, described accurately) · 🟥 = fictional canon event · 📄 = ARG artefact source

Real trends are atmosphere. They are **never** attributed to real people or real institutions acting for the Lodge.

**Day-count convention:** Lodge documents date events as days since **14 Oct 1962** (Day 0).
